# painel-dota

Painel de estatísticas de Dota 2 para jogadores, em português, feito com dados reais de partidas.

> **Status: em construção.** Por enquanto este repositório só tem a licença e este aviso.
> O desenho do projeto (escopo, arquitetura, idiomas e SEO) está sendo definido antes de qualquer código.

## Sobre os dados

- Os dados exibidos pelo painel virão de uma API pública da comunidade (OpenDota), com partidas reais.
- Este repositório, os testes e os exemplos **nunca** contêm IDs ou apelidos de jogadores reais; só dados fictícios.
- Projeto independente, sem vínculo com a Valve, a OpenDota ou outras empresas citadas. Dota 2 é marca da Valve.
